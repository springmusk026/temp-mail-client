# Changelog

All notable changes to the temp-mail-client package will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-02-13

### Added
- Initial release
- TempMail class with OOP architecture
- Retry mechanism with exponential backoff
- Custom error handling with APIError class
- Message monitoring capabilities
- TypeScript support with full type definitions
- ES Modules support
- HTML parsing for confirmation links
- Configurable settings
- Comprehensive documentation
- MIT License

### Features
- Create temporary email addresses
- Monitor incoming messages in real-time
- Extract confirmation links from HTML emails
- Custom message processing callbacks
- Configurable retry logic and polling intervals

### Technical Details
- ES Module format
- TypeScript declarations
- Private class fields
- Async/await API
- Comprehensive error handling
- Cheerio for HTML parsing
